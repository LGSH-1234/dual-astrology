# 双模式 AI 占星作品集 · 细化方案（v2，已实现）

> 状态：2026-10-01 全部功能实现完毕。单元测试 41 项、端到端测试 11 项全部通过。代码位于 `个人项目/dual-astrology`。

## 1. 定位

这是一个可演示的作品集 Web App，让用户在「紫微斗数」和「西洋占星」两种解读体系之间无刷新切换。切换后，命盘、今日运势、合盘、AI 问答都会同步变成对应体系的术语与规则。界面采用暖白、炭黑、橙色的编辑感风格，不使用任何品牌 Logo 或专有字体，和 Co–Star 也没有任何代码、文案或商标上的关联。

## 2. 相对原方案的细化与调整

| 原方案 | 调整 | 原因 |
|---|---|---|
| AstroChart 画星盘 | 自绘 SVG 星盘（`WesternWheel.tsx`） | 便于控制配色、可访问性（role=img + 描述）和移动端尺寸，也少一个依赖 |
| astrologyjs 计算 | astronomy-engine（MIT）计算行星黄经，宫位用自写的 Placidus 算法，高纬度回退到 Porphyry | astronomy-engine 精度和维护状况更好，宫位算法有单元测试验证 |
| react-iztro 组件 | 复制 react-iztro v1.5.0 的排版代码（MIT）到 `src/vendor/react-iztro/`，换成本项目配色，数据仍由 iztro 2.6.1 按真太阳时排盘 | 排版和原项目一致；授权与改动记录在 PROVENANCE |
| 未规定出生地、时区 | 内置 36 个城市的离线经纬度与 IANA 时区，通过 Intl 自动处理夏令时（含中国 1986–1991 年） | 星盘和时辰都依赖准确的 UTC 与真太阳时 |
| 未处理出生时间未知 | 支持「不清楚出生时间」：西占不计算上升和宫位，紫微按午时排盘，解读置信度降为「低」 | 这是常见的真实场景 |
| Dreamina 生成视觉 | 用即梦画布 CLI（Seedream 5.0 Lite）生成 A/B/C 三个方向的参考图（`docs/jimeng/`），选定「A 杂志排版 + C 细线轨道」，配色改为 Anthropic 官网风格的暖中性色（#faf9f5 / #141413 / #d97757） | 生成图只作参考，UI 一律代码实现，这点和原方案一致 |
| DeepSeek 预留 | 已实现服务端代理 `server/`（Hono）。默认 `INTERPRETATION_PROVIDER=mock`；配置密钥后切换为 DeepSeek，失败时自动回退到 Mock | 密钥不进前端；没有密钥也能完整演示 |

## 3. 信息架构（6 页）

1. **引导页**：填写出生资料（日期、时间或未知、城市、性别），选择默认模式和是否双视角，或一键载入示例。
2. **首页**：今日运势标题与正文、三条影响因素（西占为行运相位；紫微为大限、流年、流日）、问答入口、另一种体系的双视角卡片。
3. **命盘**：西占包括星盘、行星表、相位、宫位；紫微包括 12 宫格、宫位详情、四化。
4. **合盘**：选择或添加朋友，生成分数、总结、优势、摩擦点、沟通建议，并可以带上关系上下文深入提问。
5. **问答**：标题随模式显示「问星星」或「问紫微」，提供推荐问题、上下文标签、历史线程（带模式标记）、加载、错误与回退提示。
6. **我的**：编辑资料、偏好设置、好友管理、解读历史、AI 服务状态、隐私说明、清除数据（需二次确认）。

## 4. 合盘规则

- **西占**：比较双方行星之间的相位（太阳、月亮、金星、火星、水星、上升），叠加日月元素的相容度，水星相位用于判断沟通方式。
- **紫微**：比较主星组合（杀破狼、紫府廉武相、机月同梁、巨日），对照夫妻宫与对方命宫，检查本命禄、忌是否落入对方命宫，命宫地支关系（六合、三合、六冲、同宫），以及年支关系。
- 分数范围限定在 5–98 分，避免出现「0 分」或「100 分」这种绝对化的结论。

## 5. AI 解读

- 接口：`POST /api/interpret`，请求体为 `InterpretationRequest`，包含模式、问题、命盘摘要、关系信息和当前行运，发送前会经过 `validate.ts` 校验。
- 防护：每个 IP 每 5 分钟最多 30 次请求，请求体上限 16KB，问题长度上限 500 字。系统提示词要求以娱乐性表述为主，不给医疗、法律、投资建议，并以 JSON 格式输出。
- 回退链：DeepSeek 调用失败时回退到服务端 Mock；服务端不可达时回退到浏览器本地 Mock，并在界面上显示提示。

## 6.5 改名与 Agent 交互（2026-10-01）

产品改名为 Dio delle Stelle（星神）。界面按 Claude Code / Codex 桌面端的交互重做：多会话（`#/ask?t=id`，侧栏按今天/更早分组，可重命名、删除并撤销）；回答前逐步显示工具调用步骤，完成后折叠；打字机输出，可停止（Esc）；回答可复制、重新生成，提问可编辑后重问（丢弃之后的消息）；输入框自动增高，带模式选择、关系上下文、/ 命令和字数提示；⌘K 命令面板、⌘⇧O 新会话、⌘B 折叠侧栏、/ 聚焦输入框；移动端改为抽屉侧栏；Toast 提示。所有动画都遵守“减少动态效果”。删除了装饰性的轨道插画。

## 6.6 登录 / 注册（2026-10-01）
- 服务端账号（server/auth.ts）：邮箱 + 密码，scrypt + 随机盐，httpOnly + SameSite=Lax 会话 Cookie（服务端只存令牌 sha256），写请求要求 JSON，登录按 IP+邮箱 15 分钟 5 次失败锁定，注册按 IP 限流。数据存 SQLite（DATA_FILE，默认 server/data/dio.sqlite，已 gitignore；无 node:sqlite 时回退 JSON）。
- 资料同步：GET/PUT /api/state，每账号一份；前端防抖 800ms 推送，退出时清掉本机副本。
- DeepSeek 只对登录用户开放；游客与未登录请求走演示解读。
- 离线单文件版 / 服务端不可达：本机账号（WebCrypto PBKDF2-SHA256），只保护本机演示数据。
- 游客模式：资料只存本机；注册时自动并入新账号。

## 6.7 上线加固（2026-10-01）
- 找回密码：POST /api/auth/forgot（不区分邮箱是否存在，IP 与邮箱限流）→ 一次性令牌（只存哈希，30 分钟，DELETE…RETURNING 原子消费）→ 链接放 URL 片段；无邮件服务时打印到终端。APP_URL 未设置时只为本机地址生成链接，防 Host 头注入。POST /api/auth/reset 成功后清掉该账号全部会话并登录。
- 修改密码：POST /api/auth/password，校验旧密码，保留当前会话、踢掉其他会话；离线本机账号同样支持。
- 会话过期：前端同步收到 401 → 回登录页并提示；本机打“未同步”标记，重新登录后以本机为准上传。回到页面时检查会话。
- 网络：默认用 TCP 连接地址限流，TRUST_PROXY=true 才读 X-Forwarded-For（取最右一项）；登录另按 IP 总量限流；scrypt 改为异步。
- 安全头：nosniff、Referrer-Policy no-referrer、X-Frame-Options DENY、COOP、Permissions-Policy；页面带 CSP；HTTPS 下 HSTS + Secure Cookie；API no-store。
- 一键启动：启动.command 检查 Node 22.5+，按平台标记重装依赖，构建后由服务端同端口提供 dist，默认只监听 127.0.0.1。
